<product_requirements>
The SuperDry laundry business requires a comprehensive management system comprising 15 modules: Dashboard, Clients, Budgets, Routes, Calendar, WhatsApp, Washing/Execution, Technician Mode, Financial, Financial Manager, Reports, Tickets, Catalog, Budget Config, and System Config. Key features include unique ID generation (CLI-, ORC-, ITM-), diverse measurement types, complex status flows, Google Maps/Calendar API integration, PDF generation, WhatsApp communication, audit system, and permissions. The system must be responsive for PC and mobile.

**Implemented in Phase 1 (Initial Build & Recent Enhancements):**
*   **Dashboard:** Summary of pending items (routes, execution, financial).
*   **Clients Module:** Full CRUD, Google Places/Geocoding API for address search, GPS coordinates, auto-filled Bairro/Cidade/Estado, unique sequential IDs (CLI-), WhatsApp integration (button). Mini-maps added to client cards for visual geolocation.
*   **Catalog of Services:** Full CRUD, 11 categories, unique IDs (SRV-), multiple measurement types, active/inactive status, cost/sale values.
*   **Budgets Module:** Full CRUD, unique IDs (ORC-), integration with Clients and Catalog. Header (client, payment, salesperson, observations). Item addition with dynamic calculations. **Budget editing functionality now fully implemented (client pre-selection, save logic, toast notifications).** Quick Client Add feature implemented. WhatsApp message generation (with detailed item measurements) and PDF generation (with company logo, dynamic risk texts, and general conditions) are complete.
*   **Configurações do Orçamento (Budget Config):** New module with 11 editable risk text fields (one per category), general conditions, and footer text. Supports WhatsApp-style markdown, dynamically integrated with PDF generation.
*   **Configurações do Sistema (System Config):** New module for company details (Name, Address, CNPJ, CEP, contacts), LGPD retention policy, and future features. Includes hybrid address search and a mini-map for company location.
