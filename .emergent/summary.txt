Orçamento (Budget Config), and Config. Sistema (System Config). Key complexities include unique ID generation (CLI-, ORC-, ITM-), multiple measurement types, complex status flows, Google Maps/Calendar API integration, PDF generation, WhatsApp communication, audit system, and permissions. The system must be responsive and optimized for PC and especially for Mobile (iOS and Android).

**Implemented in Phase 1:**
- **Dashboard:** Summary with client, budget, route, scheduled service, washing, and financial stats.
- **Clients Module:** Full CRUD, Google Places API integration for address search and geolocation (GPS coordinates), auto-filling address components (Bairro, Cidade, Estado), unique sequential IDs (CLI-), WhatsApp integration.
- **Catalog of Services:** Full CRUD, 11 categories, unique sequential IDs (SRV-), multiple measurement types (Unitário, Área, Diâmetro, Metragem Linear), active/inactive status, cost/sale values. Displayed in a table format, organized by category.
- **Budgets Module:** Full CRUD, unique sequential IDs (ORC-), integration with Clients and Catalog, comprehensive header (client, payment, salesperson, observations). Item addition with dynamic calculations based on service type, editable linear meters, unique item IDs (ITM-). Items are now saved.
</product_requirements>
